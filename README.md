## 🌌 About

**System Hunter Task Diary** is a gamified productivity ecosystem inspired by the progression systems seen in Solo Leveling.

Instead of simply checking off tasks, users become **Hunters** who complete missions, gain experience, unlock ranks, build streaks, improve fitness, and compete with others.

The platform combines:

- 📅 Task Management
- 🎯 Habit Tracking
- 💪 Fitness Progression
- 🤖 AI-Generated Missions
- 🏆 Rankings & Leaderboards
- 👥 Social Features
- 🎖️ RPG Leveling System
- 🧠 Personal Growth Analytics
- 🥇 Premium Personal Trainers
